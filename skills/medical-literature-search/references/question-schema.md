# Question schema

Use JSON schema version `"1"`.

## PICO

`population` and `intervention` are required. `comparison` and `outcome` are optional.

```json
{
  "schema_version": "1",
  "framework": "PICO",
  "question": "In adults with type 2 diabetes, does continuous glucose monitoring improve HbA1c compared with self-monitoring?",
  "components": {
    "population": {
      "text": "adults with type 2 diabetes",
      "synonyms": ["adult type 2 diabetes", "T2DM"],
      "candidate_mesh": ["Diabetes Mellitus, Type 2"]
    },
    "intervention": {
      "text": "continuous glucose monitoring",
      "synonyms": ["CGM"],
      "candidate_mesh": ["Continuous Glucose Monitoring"]
    },
    "comparison": {"text": "self-monitoring of blood glucose", "synonyms": ["SMBG"]},
    "outcome": {"text": "glycated hemoglobin", "synonyms": ["HbA1c"]}
  },
  "filters": {},
  "exclude_sources": []
}
```

## PCC

`population` and `concept` are required. `context` is optional.

```json
{
  "schema_version": "1",
  "framework": "PCC",
  "question": "How are large language models used for communication training in medical students?",
  "components": {
    "population": {"text": "medical students", "synonyms": ["undergraduate medical education"]},
    "concept": {"text": "large language models", "synonyms": ["LLM", "generative AI"]},
    "context": {"text": "communication skills training", "synonyms": ["clinical communication"]}
  },
  "filters": {
    "from_date": "2020-01-01",
    "to_date": "2026-08-08",
    "languages": ["English"],
    "publication_types": []
  }
}
```

Each concept object accepts:

- `text`: required canonical phrase.
- `synonyms`: free-text variants proposed by the agent.
- `candidate_mesh`: possible headings to validate against NCBI MeSH.
- `resolved_mesh`: generated by the CLI; do not populate unless already validated.

Top-level `sources` can explicitly select providers. `exclude_sources` removes providers from the
automatic selection. Valid names are `pubmed`, `pmc`, `openalex`, `semantic-scholar`, and `scopus`.

Dates must use `YYYY-MM-DD`. Review mode applies no hidden date restriction. Quick mode adds a
three-year `from_date` only when none is supplied.
