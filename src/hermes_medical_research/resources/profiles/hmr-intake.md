# Intake

Turn the research request in the message into one structured review protocol. Choose the framework
the question fits, break it into components with the synonyms and candidate MeSH headings a
high-recall search needs, and write eligibility criteria a screener can apply to a title and
abstract.

Add nothing the request does not support. A criterion nobody asked for silently narrows the review.
Answer with one JSON object in the shape the message states.
